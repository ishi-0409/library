# 思想で本を探す（仮称）

自分が考えたい問いや悩みを自然な文章で入力し、意味の近い古典文学を見つけるためのWebサービスです。

単に作品を推薦するだけでなく、作品同士の影響、共通テーマ、対照、時代背景を関係マップで示し、「なぜ関連するのか」を理解しながら次に読む作品を選べる体験を目指しています。

> [!IMPORTANT]
> 現在は再設計中です。リポジトリ内のコードはDynamoDBとキーワード一致を使用する旧実装であり、ベクトル検索と関係グラフを使用する新仕様はまだ実装されていません。

## プロダクトの目的

### 課題

- 古典文学に興味があっても、作品数が多く、最初の一冊を選びにくい。
- 書名や著者を知らないと、自分の関心から作品を探しにくい。
- 一冊を読んだ後、次にどの作品を読めば理解が深まるのか分かりにくい。
- 作品同士の影響や共通点、相違点を知る機会が少ない。

### 解決方針

1. 利用者が悩みや考えたい問いを自然文で入力する。
2. 入力文をベクトル化し、意味の近い古典文学を候補として取得する。
3. 一致した問い・テーマと推薦理由を表示する。
4. 作品詳細で、作品同士の関係とその根拠を表示する。
5. 関係マップから、次に読む作品や理解を深める思想書・哲学書へ進めるようにする。

## 対象ユーザー

思想・古典文学に関心はあるものの専門知識がなく、何から読み始め、次に何を読めばよいか分からない大学生・若手社会人を主な対象としています。

## 目標とするMVP

### 一般利用者向け

- ログイン不要の自然文検索
- ベクトル類似度を使った古典文学の推薦
- 推薦理由、一致した問い・テーマの表示
- 作品概要と日本語出版版の表示
- 作品同士の関係マップと関係説明
- 関連作品を中心にした再探索
- 文学作品の問いを深める思想書・哲学書・随筆の別枠表示
- 関係マップと同じ情報を確認できるアクセシブルな一覧表示

### 管理者向け

- 単一管理者アカウントによる認証
- 作品、出版版、著者、テーマ、類語の管理
- 検索用文章と埋め込みベクトルの生成・更新
- 作品間関係、根拠、共通点、相違点の管理
- 公開・非公開状態の管理

## カタログ方針

- 小説、戯曲、詩などの古典文学を中心作品として扱います。
- 文学作品の問い・背景・影響を理解するために必要な思想書、哲学書、随筆を関連書として追加できます。
- 作品や出版版の読みにくさを理由に推薦順位を下げません。
- ページ数、翻訳の特徴、注釈・解説の有無、読み進める際のヒントを出版版ごとに提示します。
- 作品間関係は、管理者が内容を確認した情報だけを公開します。

## 現在の実装

現行コードは、入力に含まれる単語を類語辞書で拡張し、DynamoDBに登録されたキーワードとの一致数で本を順位付けします。

### 実装済み

- キーワードと類語による本の検索
- マッチ度、ジャンル、表紙、著者情報の表示
- 登録キーワードを使った類似本検索
- FastAPIをAWS Lambda上で動かすAPI
- React/Viteフロントエンド
- TerraformによるAWSリソース定義
- `main`ブランチへのpushを起点とするGitHub Actionsデプロイ

### 新仕様との差分

| 項目 | 現在 | 目標 |
|---|---|---|
| 検索方式 | キーワード・類語の部分一致 | 自然文のベクトル検索と再採点 |
| データ | DynamoDBの本データ | 作品、出版版、問い、テーマ、ベクトル、作品間関係 |
| 関係性 | 同じキーワードによる再検索 | 根拠付きの関係グラフ |
| 作品詳細 | 検索結果カードと外部リンク | アプリ内の作品詳細と出版版情報 |
| 管理機能 | ローカルのCSV投入ツール | 認証付き管理画面 |
| テスト | 自動テスト未整備 | 受け入れ条件と検索評価データによる検証 |

## 現行システム構成

```text
Internet
├── CloudFront → S3 → React/Vite
└── API Gateway → Lambda → FastAPI/Mangum → DynamoDB
```

| 領域 | 現在の技術 |

| Frontend | React / Vite |
| Backend | FastAPI / Mangum |
| Database | Amazon DynamoDB |
| Infrastructure | AWS Lambda / API Gateway / S3 / CloudFront |
| IaC | Terraform |
| CI/CD | GitHub Actions |
